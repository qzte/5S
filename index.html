Dados

A exportação gera uma cópia de segurança completa: histórico de auditorias, serviços, repositores/picking e perguntas. A importação permite fundir com os dados actuais (sem duplicar) ou substituir tudo. A exportação para Excel serve para análise noutro programa (uma folha por auditoria e outra por resposta) e não pode ser importada de volta: a cópia de segurança é a JSON.

Os dados ficam guardados apenas neste dispositivo. Faça exportações regulares como cópia de segurança.

Painel e-ink

O painel e-ink (a app painel.html, do repositório qzte/e-ink_panel) mostra uma página com as auditorias 5S: a média por pilar e a última auditoria de cada serviço. Esta app grava o ficheiro 5s.painel.json numa pasta partilhada — a mesma das outras apps e do painel.html —, escolhida uma vez. Volta a gravá-lo sempre que uma auditoria é gravada, editada ou apagada. Só no Chrome ou no Edge de computador.

Importar Excel (códigos e descrições)

Carregue um ficheiro .xlsx / .xls / .csv com:
· Folha Serviços — colunas Código e Descrição (ficam disponíveis no formulário como "Descrição (Código)").
· Folha Repositor ou Picking — coluna Nome (e opcionalmente Código) para sugestões nos campos Repositor/Verificador.
As folhas são reconhecidas pelo nome; num ficheiro de folha única aplica-se a deteção pelas colunas.

Perguntas por amostra

Responsáveis

Quem responde por cada pergunta. São os eixos do radar "Por responsável" e os blocos de recomendações do relatório, pela ordem em que aparecem aqui.
O código é a referência que cada pergunta guarda: fixa-se ao criar e não muda mais. O nome é só o que se lê, e pode ser corrigido a qualquer momento. As alterações só se aplicam ao carregar em Guardar responsáveis, com código de acesso.

Editor de perguntas

Área reservada ao administrador. Permite alterar perguntas, responsáveis e parâmetros de avaliação.

Perguntas da auditoria

Contagem: 0 = Excelente · até (limiar−1) = Oportunidade · ≥ limiar = Mau.
Escala 0–2: a resposta é a própria pontuação.
Elementos: máximo = Excelente · 1 ou mais = Oportunidade · 0 = Mau.
